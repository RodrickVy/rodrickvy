## The problem

Schools in remote areas often have devices but no reliable internet, so online learning resources are out of reach.

## What I did

As a volunteer with TIES, I set up **RACHEL** units on Raspberry Pi hardware. Each unit runs as a local Wi-Fi hotspot and web server, serving educational websites, textbooks, and videos entirely offline.

- Installed and configured the RACHEL software on Raspberry Pi
- Set up each Pi as a wireless access point with local DNS
- Loaded and tested the content packages before shipping

## Takeaway

This was my first hands-on networking project, and it showed me how much a small, well-configured device can do.
